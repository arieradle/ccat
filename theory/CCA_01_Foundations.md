## 0. Purpose and status conventions

Cyclotomic Coefficient Arithmetic studies arithmetic coincidences among structured polynomial values by resolving them into root-of-unity contexts. Its basic dictionary is

\[
\boxed{
\text{common arithmetic spacing}
\longleftrightarrow
\text{cyclotomic congruence}
\longleftrightarrow
\text{root-of-unity collision}
\longleftrightarrow
\text{agreement of local jets}.
}
\]

This chapter develops the general algebraic language required by all later parts of the theory.

The following labels are used throughout the monograph.

- **Definition:** terminology introduced for the theory.
- **Classical theorem:** a previously known result, included with proof because it is structural input.
- **Project theorem:** a result established inside this project.
- **Corollary:** a formal consequence of earlier results.
- **Caution:** a distinction that must be preserved in proofs and software.

The material in this chapter is exact. No numerical approximation to a root of unity is required.

# 1. Coefficient-value arithmetic

## 1.1 Distinct coefficient values

Let

\[
P(q)=\sum_{i=0}^{N}a_iq^i\in\mathbb Z[q].
\]

The **coefficient-value set** of \(P\) is

\[
U(P)=\{a_i:0\le i\le N\}.
\]

For each value \(c\in U(P)\), its **position class** is

\[
S_c(P)=\{i:a_i=c\}.
\]

Thus the coefficient data of \(P\) separates into:

1. the values that occur;
2. the number of distinct values;
3. the positions at which equal values occur.

The present theory concentrates on the arithmetic of the first item while retaining the third as collision geometry.

## 1.2 Coefficient-spacing gcd

### Definition 1.1 — Coefficient-spacing gcd

If \(|U(P)|\ge2\), define

\[
\Delta_{\mathrm{coeff}}(P)
=
\gcd\{|a-b|:a,b\in U(P),\ a\ne b\}.
\]

If \(|U(P)|\le1\), set

\[
\Delta_{\mathrm{coeff}}(P)=0.
\]

The convention \(\gcd(0,0,\ldots)=0\) makes this compatible with the difference-ideal formulation below.

### Proposition 1.2 — Basepoint formula

For any fixed coefficient value \(a_*\in U(P)\),

\[
\boxed{
\Delta_{\mathrm{coeff}}(P)
=
\gcd\{a-a_*:a\in U(P)\}.
}
\]

#### Proof

Let

\[
g=\gcd\{a-a_*:a\in U(P)\}.
\]

For any \(a,b\in U(P)\),

\[
a-b=(a-a_*)-(b-a_*),
\]

so \(g\mid a-b\). Hence \(g\) divides the gcd of all pairwise differences.

Conversely, every difference \(a-a_*\) is itself one of the pairwise differences. Therefore the gcd of all pairwise differences divides \(g\). The two gcds are equal. ∎

### Proposition 1.3 — Residue-class characterization

For an integer \(m\ge1\), the following are equivalent:

1. all coefficients of \(P\) are congruent modulo \(m\);
2. \(m\mid \Delta_{\mathrm{coeff}}(P)\).

#### Proof

If all coefficients are congruent modulo \(m\), every pairwise difference is divisible by \(m\), and therefore their gcd is divisible by \(m\).

Conversely, if \(m\mid\Delta_{\mathrm{coeff}}(P)\), then \(m\) divides every pairwise difference. Hence all coefficients lie in one residue class modulo \(m\). ∎

### Proposition 1.4 — Difference ideal

Let

\[
I(P)=\bigl(a_i-a_j:0\le i,j\le N\bigr)\subseteq\mathbb Z.
\]

Then

\[
\boxed{
I(P)=\Delta_{\mathrm{coeff}}(P)\mathbb Z.
}
\]

#### Proof

Every ideal of \(\mathbb Z\) is principal and is generated by the nonnegative gcd of any generating set. The generators of \(I(P)\) are exactly the coefficient differences. ∎

This ideal formulation is the correct algebraic meaning of coefficient spacing: it is the universal modulus under which all coefficient values collapse to one value.

# 2. Spacing in polynomial families

The central Gaussian results concern a family of polynomial values rather than the coefficients of one polynomial. The same difference-ideal principle applies.

Let \(R\) be a unique factorization domain, and let

\[
\mathcal F=\{F_k(q):k\in\mathcal K\}\subseteq R[q]
\]

be a finite nonempty family.

### Definition 2.1 — Polynomial-family spacing

If the family contains at least two distinct polynomials, define its monic spacing polynomial by

\[
\Delta_{\mathcal F}(q)
=
\gcd_{i,j\in\mathcal K}
\bigl(F_i(q)-F_j(q)\bigr),
\]

where the gcd is normalized to be monic whenever the coefficient ring permits this normalization.

If all members of the family are equal, set \(\Delta_{\mathcal F}(q)=0\).

### Proposition 2.2 — Basepoint formula for a family

Fix \(k_0\in\mathcal K\). Then

\[
\boxed{
\Delta_{\mathcal F}(q)
=
\gcd_{k\in\mathcal K}
\bigl(F_k(q)-F_{k_0}(q)\bigr).
}
\]

#### Proof

The proof is identical to Proposition 1.2. Every pairwise difference satisfies

\[
F_i-F_j=(F_i-F_{k_0})-(F_j-F_{k_0}),
\]

while every basepoint difference is already a pairwise difference. ∎

### Proposition 2.3 — Congruence-collapse criterion

Let \(H(q)\in R[q]\) be nonzero. Then

\[
\boxed{
H(q)\mid\Delta_{\mathcal F}(q)
\iff
F_i(q)\equiv F_j(q)\pmod{H(q)}
\quad\text{for all }i,j\in\mathcal K.
}
\]

Equivalently, \(H\mid\Delta_{\mathcal F}\) precisely when the image of the entire family in \(R[q]/(H)\) consists of a single point.

#### Proof

By definition, \(H\mid\Delta_{\mathcal F}\) if and only if \(H\) divides every pairwise difference \(F_i-F_j\). This is exactly the stated congruence condition. ∎

### Definition 2.4 — Contextual collapse

When \(H=\Phi_d\) is cyclotomic and Proposition 2.3 holds, the family is said to **collapse in the cyclotomic context \(d\)**.

The terminology reflects the fact that all family members have the same value at every primitive \(d\)-th root of unity.

# 3. Cyclotomic contexts and valuations

## 3.1 Cyclotomic factorization

For \(m\ge1\), let \(\Phi_m(q)\in\mathbb Z[q]\) denote the \(m\)-th cyclotomic polynomial. In characteristic zero,

\[
q^m-1=\prod_{d\mid m}\Phi_d(q).
\]

The factors are distinct because \(q^m-1\) has no repeated root over a field of characteristic zero:

\[
\gcd(q^m-1,mq^{m-1})=1.
\]

Hence each \(\Phi_d\) occurs with multiplicity one in \(q^m-1\).

### Definition 3.1 — Cyclotomic valuation

For a nonzero rational function \(F(q)\in\mathbb Q(q)\), define

\[
v_{\Phi_d}(F)
\]

to be the exponent of \(\Phi_d(q)\) in the unique factorization of \(F\). Thus

\[
v_{\Phi_d}(FG)=v_{\Phi_d}(F)+v_{\Phi_d}(G),
\]

and

\[
v_{\Phi_d}(F/G)=v_{\Phi_d}(F)-v_{\Phi_d}(G).
\]

For \(F\in\mathbb Z[q]\setminus\{0\}\), this valuation is a nonnegative integer.

## 3.2 Divisibility and primitive-root evaluation

### Proposition 3.2 — First-order root criterion

Let \(P(q)\in\mathbb Q[q]\), let \(d\ge1\), and let \(\zeta\) be any primitive \(d\)-th root of unity. Then

\[
\boxed{
\Phi_d(q)\mid P(q)
\iff
P(\zeta)=0.
}
\]

#### Proof

If \(\Phi_d\mid P\), then \(P\) vanishes at every root of \(\Phi_d\), including \(\zeta\).

Conversely, \(\Phi_d\) is the minimal polynomial of \(\zeta\) over \(\mathbb Q\). If \(P(\zeta)=0\), the minimal polynomial divides \(P\) in \(\mathbb Q[q]\). Since \(\Phi_d\) is monic and primitive, Gauss's lemma gives the corresponding divisibility in \(\mathbb Z[q]\) when \(P\in\mathbb Z[q]\). ∎

### Corollary 3.3 — Cyclotomic collapse as root collision

For a polynomial family \(\mathcal F=\{F_k\}\subseteq\mathbb Q[q]\),

\[
\boxed{
\Phi_d\mid\Delta_{\mathcal F}
\iff
F_k(\zeta)
\text{ is independent of }k
}
\]

for one, equivalently every, primitive \(d\)-th root \(\zeta\).

#### Proof

Apply Proposition 3.2 to every difference \(F_i-F_j\), then use Proposition 2.3. Since the coefficients are rational, vanishing at one primitive root implies divisibility by \(\Phi_d\), and hence vanishing at all primitive roots. ∎

# 4. Compressed \(q\)-factorial quotients

## 4.1 Notation

Define the finite \(q\)-Pochhammer symbol

\[
(q;q)_m=\prod_{j=1}^{m}(1-q^j),
\qquad
(q;q)_0=1.
\]

A **compressed \(q\)-factorial quotient** is an expression

\[
F(q)=q^\alpha\prod_{i=1}^{r}(q;q)_{a_i}^{\varepsilon_i},
\]

where

\[
\alpha\in\mathbb Z,
\qquad
a_i\in\mathbb Z_{\ge0},
\qquad
\varepsilon_i\in\mathbb Z.
\]

The expression is treated structurally; it need not be expanded. It may represent a rational function rather than a polynomial.

## 4.2 Valuation of a \(q\)-factorial

### Theorem 4.1 — \(q\)-factorial cyclotomic valuation

For all integers \(m\ge0\) and \(d\ge1\),

\[
\boxed{
v_{\Phi_d}\bigl((q;q)_m\bigr)
=
\left\lfloor\frac md\right\rfloor.
}
\]

#### Proof

Factor each term:

\[
1-q^j=-(q^j-1)
=-\prod_{e\mid j}\Phi_e(q).
\]

The factor \(\Phi_d(q)\) occurs in \(1-q^j\) exactly when \(d\mid j\), and then occurs with multiplicity one because the cyclotomic factorization of \(q^j-1\) is squarefree.

Therefore the multiplicity of \(\Phi_d\) in

\[
(q;q)_m=\prod_{j=1}^{m}(1-q^j)
\]

is the number of multiples of \(d\) among \(1,2,\ldots,m\), namely

\[
\left\lfloor\frac md\right\rfloor.
\]

∎

### Theorem 4.2 — Valuation of a compressed quotient

For

\[
F(q)=q^\alpha\prod_{i=1}^{r}(q;q)_{a_i}^{\varepsilon_i},
\]

one has

\[
\boxed{
v_{\Phi_d}(F)
=
\sum_{i=1}^{r}\varepsilon_i
\left\lfloor\frac{a_i}{d}\right\rfloor.
}
\]

#### Proof

The monomial \(q^\alpha\) is coprime to every cyclotomic polynomial \(\Phi_d(q)\) with \(d\ge1\), because \(\Phi_d(0)=\pm1\). Thus

\[
v_{\Phi_d}(q^\alpha)=0.
\]

Cyclotomic valuation is additive under multiplication and subtraction of exponents under division. Applying Theorem 4.1 factor by factor gives

\[
\begin{aligned}
v_{\Phi_d}(F)
&=
\sum_{i=1}^{r}\varepsilon_i
v_{\Phi_d}\bigl((q;q)_{a_i}\bigr)\\
&=
\sum_{i=1}^{r}\varepsilon_i
\left\lfloor\frac{a_i}{d}\right\rfloor.
\end{aligned}
\]

∎

### Corollary 4.3 — Polynomiality test inside the factorial-quotient class

If \(F(q)\) is known a priori to be a Laurent polynomial, then

\[
v_{\Phi_d}(F)\ge0
\qquad(d\ge1).
\]

Conversely, for a quotient built only from \(q\), \(q^{-1}\), and the factors \((q;q)_{a_i}\), nonnegativity of all cyclotomic valuations is sufficient for the quotient to be a Laurent polynomial up to an overall sign.

#### Proof

Necessity is immediate for every Laurent polynomial because cyclotomic polynomials are nonunits and cannot occur with negative exponent.

For sufficiency, factor every \((q;q)_{a_i}\) into cyclotomic polynomials. If every resulting cyclotomic exponent is nonnegative, all denominator cyclotomic factors cancel. The only remaining possible negative exponent comes from the explicitly supplied monomial \(q^\alpha\), so the result is a Laurent polynomial. ∎

### Computational consequence

The value \(v_{\Phi_d}(F)\) can be computed using only integer division on the compressed parameters. Its running time depends on the number and bit lengths of the \(a_i\), not on the degree or number of coefficients of the expanded expression.

# 5. Gaussian binomial coefficients

## 5.1 Definition

For integers \(n\ge0\) and \(0\le k\le n\), define

\[
{n\brack k}_q
=
\frac{(q;q)_n}{(q;q)_k(q;q)_{n-k}}.
\]

Set \({n\brack k}_q=0\) when \(k<0\) or \(k>n\).

## 5.2 Cyclotomic valuation law

### Theorem 5.1 — Gaussian cyclotomic valuation

For \(0\le k\le n\),

\[
\boxed{
v_{\Phi_d}\left({n\brack k}_q\right)
=
\left\lfloor\frac nd\right\rfloor
-
\left\lfloor\frac kd\right\rfloor
-
\left\lfloor\frac{n-k}{d}\right\rfloor.
}
\]

Moreover, this valuation belongs to \(\{0,1\}\).

#### Proof

The displayed formula follows immediately from Theorem 4.2.

To prove the range, write

\[
k=rd+s,
\qquad
0\le s<d,
\]

and

\[
n=ad+b,
\qquad
0\le b<d.
\]

If \(s\le b\), then

\[
n-k=(a-r)d+(b-s),
\]

so

\[
\left\lfloor\frac{n-k}{d}\right\rfloor=a-r.
\]

The valuation is

\[
a-r-(a-r)=0.
\]

If \(s>b\), then

\[
n-k=(a-r-1)d+(d+b-s),
\]

with \(0\le d+b-s<d\), so

\[
\left\lfloor\frac{n-k}{d}\right\rfloor=a-r-1.
\]

The valuation is

\[
a-r-(a-r-1)=1.
\]

Thus the valuation is always \(0\) or \(1\). ∎

### Corollary 5.2 — Carry criterion

With

\[
n=ad+b,
\qquad
k=rd+s,
\qquad
0\le b,s<d,
\]

one has

\[
\boxed{
v_{\Phi_d}\left({n\brack k}_q\right)=1
\iff
s>b.
}
\]

Equivalently, the valuation records whether subtraction of \(k\) from \(n\) requires a borrow in the least significant base-\(d\) digit.

#### Proof

This is exactly the case distinction in the proof of Theorem 5.1. ∎

The carry criterion is the first appearance of a recurring principle: cyclotomic depth is controlled by residue defects.

# 6. The \(q\)-Lucas contextual fingerprint

## 6.1 Finite \(q\)-binomial theorem

We first prove the generating identity used in the \(q\)-Lucas theorem.

### Lemma 6.1 — Finite \(q\)-binomial theorem

For \(n\ge0\),

\[
\boxed{
\prod_{j=0}^{n-1}(1+q^jx)
=
\sum_{k=0}^{n}
q^{\binom{k}{2}}
{n\brack k}_q x^k.
}
\]

#### Proof

Proceed by induction on \(n\). The formula is immediate for \(n=0\).

Assume it holds for \(n\). Multiplying by \(1+q^nx\) gives

\[
\begin{aligned}
\prod_{j=0}^{n}(1+q^jx)
&=
\sum_{k=0}^{n}q^{\binom{k}{2}}{n\brack k}_q x^k
+
\sum_{k=0}^{n}q^{n+\binom{k}{2}}{n\brack k}_q x^{k+1}.
\end{aligned}
\]

The coefficient of \(x^k\) is

\[
q^{\binom{k}{2}}{n\brack k}_q
+
q^{n+\binom{k-1}{2}}{n\brack k-1}_q.
\]

Since

\[
n+\binom{k-1}{2}
=
\binom{k}{2}+n-k+1,
\]

this equals

\[
q^{\binom{k}{2}}
\left(
{n\brack k}_q
+
q^{n-k+1}{n\brack k-1}_q
\right).
\]

The Gaussian recurrence

\[
{n+1\brack k}_q
=
{n\brack k}_q
+
q^{n-k+1}{n\brack k-1}_q
\]

follows directly from the factorial definition, so the coefficient is

\[
q^{\binom{k}{2}}{n+1\brack k}_q.
\]

This completes the induction. ∎

## 6.2 Root-of-unity block identity

### Lemma 6.2 — Complete cyclotomic block

If \(\zeta\) is a primitive \(d\)-th root of unity, then

\[
\boxed{
\prod_{u=0}^{d-1}(1+\zeta^u x)
=
1-(-x)^d.
}
\]

#### Proof

The roots of the polynomial \(1-(-x)^d\) are exactly

\[
x=-\zeta^{-u},
\qquad 0\le u<d.
\]

The product on the left has the same roots and constant term \(1\). Both sides have degree \(d\), so they are equal. ∎

## 6.3 \(q\)-Lucas theorem

### Theorem 6.3 — \(q\)-Lucas congruence

Write

\[
n=ad+b,
\qquad
k=rd+s,
\qquad
0\le b,s<d.
\]

Then

\[
\boxed{
{n\brack k}_q
\equiv
\binom ar{b\brack s}_q
\pmod{\Phi_d(q)}.
}
\]

The convention \({b\brack s}_q=0\) for \(s>b\) is understood.

#### Proof

Let \(\zeta\) be a primitive \(d\)-th root of unity. By Lemma 6.1,

\[
\prod_{j=0}^{n-1}(1+\zeta^jx)
=
\sum_{k=0}^{n}
\zeta^{\binom{k}{2}}
{n\brack k}_{\zeta}x^k.
\]

Split the product into \(a\) complete blocks of length \(d\) and one final block of length \(b\):

\[
\begin{aligned}
\prod_{j=0}^{ad+b-1}(1+\zeta^jx)
&=
\left(
\prod_{u=0}^{d-1}(1+\zeta^ux)
\right)^a
\prod_{u=0}^{b-1}(1+\zeta^ux)\\
&=
\bigl(1-(-x)^d\bigr)^a
\prod_{u=0}^{b-1}(1+\zeta^ux),
\end{aligned}
\]

using Lemma 6.2.

Expand both factors:

\[
\bigl(1-(-x)^d\bigr)^a
=
\sum_{r'=0}^{a}
(-1)^{r'(d+1)}\binom a{r'}x^{r'd},
\]

and

\[
\prod_{u=0}^{b-1}(1+\zeta^ux)
=
\sum_{s'=0}^{b}
\zeta^{\binom{s'}{2}}{b\brack s'}_{\zeta}x^{s'}.
\]

Because \(0\le s<d\) and the second factor has degree \(b<d\), the coefficient of \(x^{rd+s}\) comes uniquely from \(r'=r\) and \(s'=s\). It is therefore

\[
(-1)^{r(d+1)}\binom ar
\zeta^{\binom{s}{2}}{b\brack s}_{\zeta}.
\]

On the other hand, the coefficient supplied by the left side of the finite \(q\)-binomial theorem is

\[
\zeta^{\binom{rd+s}{2}}{ad+b\brack rd+s}_{\zeta}.
\]

It remains to compare the phase factors. We claim

\[
\zeta^{\binom{rd+s}{2}-\binom{s}{2}}
=
(-1)^{r(d+1)}.
\]

Indeed,

\[
\binom{rd+s}{2}-\binom{s}{2}
=
\frac{rd(rd+2s-1)}2.
\]

Writing \(\zeta=e^{2\pi i/d}\), the left side becomes

\[
\exp\bigl(\pi i\,r(rd+2s-1)\bigr)
=
(-1)^{r(rd+2s-1)}.
\]

The parity difference between the exponents

\[
r(rd+2s-1)
\quad\text{and}\quad
r(d+1)
\]

is

\[
r\bigl(d(r-1)+2(s-1)\bigr),
\]

which is even because \(r(r-1)\) is even. Hence the phases agree.

Cancelling the common phase gives

\[
{ad+b\brack rd+s}_{\zeta}
=
\binom ar{b\brack s}_{\zeta}.
\]

Thus the polynomial

\[
{ad+b\brack rd+s}_{q}
-
\binom ar{b\brack s}_{q}
\]

vanishes at \(\zeta\). By Proposition 3.2, it is divisible by \(\Phi_d(q)\). ∎

## 6.4 Contextual fingerprint

### Definition 6.4 — Gaussian contextual fingerprint

For fixed \(n\) and \(d\), write

\[
n=ad+b,
\qquad
k=r_kd+s_k,
\qquad
0\le b,s_k<d.
\]

Define

\[
\boxed{
\Lambda_{n,d}(k)
=
\binom{a}{r_k}{b\brack s_k}_q
\in
\mathbb Z[q]/(\Phi_d(q)).
}
\]

By Theorem 6.3, \(\Lambda_{n,d}(k)\) is exactly the image of \({n\brack k}_q\) in the \(d\)-th cyclotomic quotient.

### Project Theorem 6.5 — Arbitrary-subset contextual-collapse criterion

Let \(\mathcal K\subseteq\{0,1,\ldots,n\}\) be nonempty, and define

\[
\Delta_{n,\mathcal K}(q)
=
\gcd_{i,j\in\mathcal K}
\left(
{n\brack i}_q-{n\brack j}_q
\right).
\]

Then

\[
\boxed{
\Phi_d(q)\mid\Delta_{n,\mathcal K}(q)
\iff
\Lambda_{n,d}(k)
\text{ is constant for }k\in\mathcal K.
}
\]

#### Proof

By Proposition 2.3,

\[
\Phi_d\mid\Delta_{n,\mathcal K}
\]

if and only if all retained Gaussian coefficients have the same residue modulo \(\Phi_d\).

By Theorem 6.3, the residue of \({n\brack k}_q\) is \(\Lambda_{n,d}(k)\). Therefore all retained coefficients have the same residue exactly when \(\Lambda_{n,d}(k)\) is constant on \(\mathcal K\). ∎

### Corollary 6.6 — Zero-fingerprint collapse

If

\[
s_k>b
\qquad\text{for every }k\in\mathcal K,
\]

then

\[
\Phi_d(q)\mid\Delta_{n,\mathcal K}(q).
\]

#### Proof

If \(s_k>b\), then \({b\brack s_k}_q=0\), so every fingerprint is zero. Apply Theorem 6.5. ∎

### Corollary 6.7 — Valuation interpretation of the zero fingerprint

For a single Gaussian coefficient,

\[
\Lambda_{n,d}(k)=0
\iff
v_{\Phi_d}\left({n\brack k}_q\right)=1.
\]

#### Proof

The fingerprint is zero precisely when \(s_k>b\). By Corollary 5.2, that condition is equivalent to cyclotomic valuation one. ∎

The nonzero fingerprints contain finer information than valuation: two coefficients can both have valuation zero but still have different nonzero residues modulo \(\Phi_d\).

# 7. Local cyclotomic geometry

The congruence theory above detects whether two polynomials agree to order zero at a primitive root. Higher collision multiplicity is governed by local derivatives.

## 7.1 Local ring at a primitive root

Fix \(d\ge1\), a primitive \(d\)-th root \(\zeta\), and the cyclotomic field

\[
K=\mathbb Q(\zeta).
\]

Let

\[
\mathscr O_{\zeta}=K[q]_{(q-\zeta)}
\]

be the localization of \(K[q]\) at the maximal ideal \((q-\zeta)\). Its elements are rational functions regular at \(q=\zeta\).

### Definition 7.1 — Contextual depth

For nonzero \(F\in\mathscr O_{\zeta}\), define

\[
\operatorname{depth}_{\zeta}(F)
=
\max\{r\ge0:F\in(q-\zeta)^r\mathscr O_{\zeta}\}.
\]

Equivalently, it is the ordinary order of vanishing of \(F\) at \(q=\zeta\).

Set \(\operatorname{depth}_{\zeta}(0)=+\infty\).

## 7.2 Association of local parameters

### Lemma 7.2 — Local equivalence of \(q-\zeta\), \(q^d-1\), and \(\Phi_d(q)\)

In \(\mathscr O_{\zeta}\), the three elements

\[
q-\zeta,
\qquad
q^d-1,
\qquad
\Phi_d(q)
\]

differ pairwise by multiplication by units.

#### Proof

Since \(\zeta^d=1\),

\[
q^d-1=(q-\zeta)u_{d,\zeta}(q),
\]

where

\[
u_{d,\zeta}(\zeta)
=
\left.\frac{d}{dq}(q^d-1)\right|_{q=\zeta}
=
d\zeta^{d-1}\ne0.
\]

Therefore \(u_{d,\zeta}\) is a unit in the local ring.

Likewise, \(\zeta\) is a simple root of \(\Phi_d\), because cyclotomic polynomials are separable in characteristic zero. Thus

\[
\Phi_d(q)=(q-\zeta)v_{d,\zeta}(q),
\]

with

\[
v_{d,\zeta}(\zeta)=\Phi_d'(\zeta)\ne0.
\]

Hence \(v_{d,\zeta}\) is also a local unit. ∎

### Project Theorem 7.3 — Local-context valuation theorem

For every nonzero \(P(q)\in\mathbb Q[q]\),

\[
\boxed{
\operatorname{depth}_{\zeta}(P)
=
v_{\Phi_d}(P).
}
\]

More generally, the equality holds for rational functions after allowing both sides to take arbitrary integer values.

#### Proof

Factor \(P\) in \(\mathbb Q[q]\) as

\[
P(q)=\Phi_d(q)^hG(q),
\qquad
\Phi_d\nmid G.
\]

By Lemma 7.2,

\[
\Phi_d(q)^h=(q-\zeta)^h u(q)
\]

for a local unit \(u\).

Because \(G\) is not divisible by the minimal polynomial \(\Phi_d\), one has \(G(\zeta)\ne0\), so \(G\) is also a unit in \(\mathscr O_{\zeta}\). Therefore

\[
P(q)=(q-\zeta)^h\cdot\text{(unit)},
\]

and its local depth is exactly \(h=v_{\Phi_d}(P)\).

For a rational function, apply the same argument to numerator and denominator and subtract orders. ∎

This theorem converts an algebraic factor multiplicity into a geometric contact order at a root-of-unity context.

# 8. Exponential local coordinate and jets

## 8.1 Euler derivation

Define the Euler derivation

\[
D=q\frac{d}{dq}.
\]

Use the exponential coordinate

\[
q=\zeta e^x.
\]

For a function \(F\) regular at \(\zeta\), set

\[
f_{\zeta}(x)=F(\zeta e^x).
\]

Then the chain rule gives

\[
\frac{d}{dx}f_{\zeta}(x)
=
\zeta e^xF'(\zeta e^x)
=
(DF)(\zeta e^x).
\]

Iterating,

\[
\boxed{
f_{\zeta}^{(j)}(0)=D^jF(\zeta).
}
\]

Moreover,

\[
q-\zeta
=
\zeta(e^x-1)
=
\zeta x+O(x^2),
\]

so \(x\) and \(q-\zeta\) are associated local parameters and define the same vanishing order.

## 8.2 Jet criterion

### Project Theorem 8.1 — Cyclotomic jet criterion

Let \(P(q)\in\mathbb Q[q]\), let \(r\ge1\), and let \(\zeta\) be primitive of order \(d\). Then

\[
\boxed{
v_{\Phi_d}(P)\ge r
\iff
D^jP(\zeta)=0
\quad(0\le j<r).
}
\]

#### Proof

Set

\[
f(x)=P(\zeta e^x).
\]

By the exponential-coordinate calculation,

\[
f^{(j)}(0)=D^jP(\zeta).
\]

A one-variable analytic or formal power series has order at least \(r\) at \(x=0\) if and only if its first \(r\) Taylor coefficients vanish, equivalently

\[
f^{(j)}(0)=0
\qquad(0\le j<r).
\]

Because \(x\) and \(q-\zeta\) are associated local parameters, the order of \(f\) in \(x\) is \(\operatorname{depth}_{\zeta}(P)\). By Theorem 7.3, this is \(v_{\Phi_d}(P)\). Combining these equivalences proves the theorem. ∎

### Project Theorem 8.2 — Collision hierarchy

For \(P,Q\in\mathbb Q[q]\) and \(r\ge1\),

\[
\boxed{
v_{\Phi_d}(P-Q)\ge r
\iff
D^jP(\zeta)=D^jQ(\zeta)
\quad(0\le j<r).
}
\]

#### Proof

Apply Theorem 8.1 to the polynomial \(P-Q\), noting that

\[
D^j(P-Q)=D^jP-D^jQ.
\]

∎

### Definition 8.3 — Cyclotomic jet

The order-\(r\) cyclotomic jet of \(P\) at the context \((d,\zeta)\) is

\[
J_{d}^{<r}(P;\zeta)
=
\bigl(P(\zeta),DP(\zeta),\ldots,D^{r-1}P(\zeta)\bigr).
\]

Theorem 8.2 states that

\[
\boxed{
P\equiv Q\pmod{\Phi_d^r}
\iff
J_d^{<r}(P;\zeta)=J_d^{<r}(Q;\zeta).
}
\]

### Corollary 8.4 — First distinguishing order

If \(P\ne Q\) and

\[
h=v_{\Phi_d}(P-Q),
\]

then

\[
D^jP(\zeta)=D^jQ(\zeta)
\qquad(0\le j<h),
\]

while

\[
D^hP(\zeta)\ne D^hQ(\zeta).
\]

#### Proof

The equality of derivatives below order \(h\) follows from Theorem 8.2 with \(r=h\). If the order-\(h\) derivatives were also equal, Theorem 8.2 with \(r=h+1\) would imply \(v_{\Phi_d}(P-Q)\ge h+1\), contradicting the definition of \(h\). ∎

### Corollary 8.5 — Galois propagation

For \(P,Q\in\mathbb Q[q]\), agreement of their jets through order \(r-1\) at one primitive \(d\)-th root is equivalent to agreement through the same order at every primitive \(d\)-th root.

#### Proof

Agreement at one primitive root is equivalent by Theorem 8.2 to divisibility of \(P-Q\) by \(\Phi_d^r\). This divisibility forces the same multiplicity at every root of \(\Phi_d\). Applying Theorem 8.2 at each conjugate root gives the result. ∎

# 9. Local normal form

### Proposition 9.1 — First nonzero local coefficient

Let \(P\in\mathbb Q[q]\setminus\{0\}\), and set

\[
h=v_{\Phi_d}(P).
\]

Then in the local ring \(\mathscr O_\zeta\),

\[
\boxed{
P(q)=(q^d-1)^hR_{d,\zeta}(q),
\qquad
R_{d,\zeta}(\zeta)\ne0.
}
\]

The factor \(R_{d,\zeta}(\zeta)\) is the leading local residual relative to the parameter \(q^d-1\).

#### Proof

By Theorem 7.3, \(P\) has local order \(h\). By Lemma 7.2, \(q^d-1\) is a uniformizing parameter, associated to \(q-\zeta\). Therefore dividing by \((q^d-1)^h\) produces a local unit \(R_{d,\zeta}\), whose value at \(\zeta\) is nonzero. ∎

### Proposition 9.2 — First visible jet from the residual

Under the hypotheses of Proposition 9.1,

\[
\boxed{
\frac{D^hP(\zeta)}{h!}
=
d^hR_{d,\zeta}(\zeta).
}
\]

#### Proof

Set \(q=\zeta e^x\). Since \(\zeta^d=1\),

\[
q^d-1=e^{dx}-1=dx+O(x^2).
\]

Also,

\[
R_{d,\zeta}(\zeta e^x)
=
R_{d,\zeta}(\zeta)+O(x).
\]

Hence

\[
P(\zeta e^x)
=
\bigl(dx+O(x^2)\bigr)^h
\bigl(R_{d,\zeta}(\zeta)+O(x)\bigr)
=
d^hR_{d,\zeta}(\zeta)x^h+O(x^{h+1}).
\]

The coefficient of \(x^h\) is \(D^hP(\zeta)/h!\), proving the formula. ∎

### Caution 9.3 — Local division is not global divisibility

The expression

\[
\frac{P(q)}{(q^d-1)^h}
\]

in Proposition 9.1 is an element of the local ring at \(q=\zeta\). It need not be a polynomial globally.

Indeed,

\[
q^d-1=\prod_{e\mid d}\Phi_e(q).
\]

The condition \(v_{\Phi_d}(P)=h\) guarantees only the factor \(\Phi_d^h\). It does not guarantee the factors \(\Phi_e^h\) for proper divisors \(e\mid d\). Those other factors are units at the primitive \(d\)-th root \(\zeta\), which is precisely why division by \((q^d-1)^h\) is valid locally.

This local/global distinction is essential in every later defect and cumulant theorem.

# 10. The foundational CGT dictionary

The results of this chapter establish the following exact correspondences.

| Arithmetic/algebraic notion | Cyclotomic-local realization |
|---|---|
| A modulus under which coefficient values coincide | Divisor of the coefficient-spacing gcd |
| A polynomial modulus under which a family collapses | Divisor of the family-spacing polynomial |
| Context of order \(d\) | A primitive root \(q=\zeta_d\), or the prime ideal \((\Phi_d)\) |
| Zeroth-order contextual fingerprint | Residue modulo \(\Phi_d\), equivalently value at \(\zeta_d\) |
| Cyclotomic depth | \(v_{\Phi_d}(P)\) |
| Local contact order | \(\operatorname{ord}_{q=\zeta_d}P\) |
| Order-\(r\) collision | Equality of the first \(r\) Euler jets |
| First distinguishing fingerprint | First derivative order at which the jets differ |
| Transverse residual | The local unit after removing \((q^d-1)^h\) |

The central foundational identity is

\[
\boxed{
\text{cyclotomic valuation}
=
\text{local contact depth}
=
\text{number of initial vanishing Euler jets}.
}
\]

For Gaussian coefficients, the order-zero contextual image is explicitly computable by \(q\)-Lucas:

\[
\boxed{
{ad+b\brack rd+s}_q
\mapsto
\binom ar{b\brack s}_q
\quad\text{in }\mathbb Z[q]/(\Phi_d).
}
\]

Therefore a potentially enormous Gaussian family can be tested for first-order cyclotomic collapse using only quotient-remainder data and small Gaussian coefficients.

# 13. Software corollary

Theorems 4.2, 5.1, 6.3, 6.5, and 8.2 suggest a layered exact-computation interface:

1. **Valuation layer:** compute \(v_{\Phi_d}\) using floor sums.
2. **Residue layer:** compute Gaussian images modulo \(\Phi_d\) using \(q\)-Lucas.
3. **Jet layer:** compare successive Euler derivatives at an exact primitive root.
4. **Certificate layer:** return the first context and derivative order distinguishing two structured expressions.

The first two layers avoid expansion completely. The later parts of the monograph derive non-expanding formulas for important higher-jet families.
